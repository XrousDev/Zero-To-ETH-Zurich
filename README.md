# Zero To ETH-Zurich

## **Free to use, but not to modify or sell**

A comprehensive study guide and question bank series for students preparing for ETH Zurich.

## About the Project
This project is a 4-part PDF series created with the assistance of AI tools to help students prepare for the ETH Zurich entrance exam. Initially created for personal use, I decided to share this resource thinking it might be useful to others.

## Contents
- **Part 1:** General tactics, study plan, mathematics, and foundational physics.
- **Part 2:** Physics (electricity, magnetism, thermodynamics, waves), biology, chemistry, German.
- **Part 3:** Advanced mathematics, advanced physics, and German C1 level.
- **Part 4:** Mock exams and exam strategies.
